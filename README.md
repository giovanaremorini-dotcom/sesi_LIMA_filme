🎀 Barbie — As 12 Princesas Bailarinas

Projeto desenvolvido para a disciplina de Desenvolvimento de Sistemas, utilizando HTML5 e CSS3, com o objetivo de criar um site temático sobre o filme Barbie: As 12 Princesas Bailarinas.

O site apresenta uma interface inspirada no universo do filme, reunindo informações sobre a história, personagens, trailer, imagens, curiosidades e um espaço para o visitante deixar sua opinião.

🎬 Sobre o projeto
O projeto consiste em uma página web temática dedicada ao filme Barbie: As 12 Princesas Bailarinas, lançado em 2006.

A proposta foi desenvolver uma página organizada e visualmente agradável utilizando os conhecimentos básicos de HTML e CSS, trabalhando com diferentes elementos de estruturação, imagens, links, formulário, navegação entre seções e estilização.

O site possui uma navegação por menu que permite acessar diferentes partes da página:

🏰 Sinopse
🎥 Trailer
👑 Elenco
🖼️ Galeria
✨ Curiosidades
💌 Contato / Opinião
✨ Funcionalidades
🏠 Página inicial

Apresenta o título do filme, uma breve descrição e um botão que direciona o visitante para a seção de sinopse.

📖 Sinopse
Apresenta informações sobre a história de Genevieve e suas irmãs, além de dados básicos do filme:

Nome
Ano de lançamento
Gênero
Pôster oficial
🎥 Trailer

Possui um vídeo incorporado do YouTube utilizando um elemento <iframe>.

👑 Personagens
A página apresenta cards com alguns dos principais personagens e suas respectivas imagens e descrições:

Genevieve
Ashlyn
Blair
Courtney
Delia
Trigêmeas
🖼️ Galeria

Seção destinada à apresentação de imagens relacionadas ao filme.

✨ Curiosidades
Apresenta diferentes informações sobre a produção e elementos presentes no filme, incluindo curiosidades relacionadas às coreografias, personagens, trilha sonora e elementos da história.

💌 Formulário de opinião
O visitante pode preencher um formulário contendo:

Nome
E-mail
Opinião sobre o filme

🎨 Identidade visual

A interface foi desenvolvida buscando representar visualmente o universo de Barbie e das princesas bailarinas, utilizando elementos decorativos, imagens do filme e uma fonte personalizada.

O arquivo style.css concentra a estilização da página, incluindo:

Cores;
Tipografia;
Espaçamentos;
Cards;
Botões;
Menu de navegação;
Galeria de imagens;
Formulário;
Rodapé;
Organização das diferentes seções.

🎯 Objetivo educacional
O projeto foi desenvolvido como uma atividade prática para aplicar conhecimentos de HTML5 e CSS3 na criação de uma página web completa.
Além de praticar a estruturação de páginas, o projeto permite trabalhar a relação entre estrutura HTML e apresentação visual utilizando CSS, desenvolvendo uma interface temática e organizada.
