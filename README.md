# 🎀 Barbie — As 12 Princesas Bailarinas

> ✨ **Projeto desenvolvido para a disciplina de Desenvolvimento de Sistemas**, utilizando **HTML e CSS**, com o objetivo de criar um site temático sobre o filme **Barbie: As 12 Princesas Bailarinas**.

---

## 🌸 Sobre o Projeto

O projeto consiste em uma página web temática dedicada ao filme **Barbie: As 12 Princesas Bailarinas**, lançado em **2006**.

A proposta foi desenvolver uma página organizada e visualmente agradável utilizando os conhecimentos básicos de **HTML e CSS**, trabalhando com:

* Estruturação de páginas;
* Imagens;
* Links;
* Navegação entre seções;
* Formulários;
* Estilização;
* Elementos visuais.

# 🎨 Identidade Visual

A interface foi desenvolvida buscando representar visualmente o universo de **Barbie e das princesas bailarinas**.

O projeto utiliza:

* 🎀 Elementos decorativos;
* 🌸 Imagens relacionadas ao filme;
* 🔤 Fonte personalizada;
* 🎨 Cores e estilos temáticos;
* 🖼️ Elementos visuais relacionados à história.

O arquivo `style.css` concentra a estilização da página.

### 🎨 Elementos estilizados

* Menu de navegação;
* Botões;
* Cards;
* Galeria;
* Formulário;
* Rodapé;
* Seções da página;
* Tipografia;
* Espaçamentos;
* Organização visual.

---

# 🧩 Estrutura HTML

O arquivo `index.html` organiza o conteúdo utilizando diferentes elementos HTML5:

```html
<header>
<nav>
<section>
<div>
<img>
<h1>
<h2>
<h3>
<p>
<form>
<input>
<textarea>
<button>
<footer>
```

A página também utiliza **IDs e classes** para permitir a organização do conteúdo e a aplicação dos estilos definidos no CSS.

# 🎯 Objetivo Educacional

O projeto foi desenvolvido como uma atividade prática para aplicar conhecimentos de **HTML e CSS** na criação de uma página web completa.

Além de praticar a estruturação de páginas, o projeto permite trabalhar a relação entre:

```text
HTML
  ↓
Estrutura
  ↓
CSS
  ↓
Apresentação Visual
  ↓
Página Web
```

O objetivo é desenvolver uma interface temática, organizada e visualmente personalizada.
